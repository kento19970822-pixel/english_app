画面イメージ（パステルカラー×ドット絵の世界観）の各デザイン仕様・設定値を項目ごとにまとめました。アプリ開発時のスタイリングやFlutter/Swift等の実装値としてご活用ください。

## 🎨 1. カラーパレット (Color Palette)

| 項目 | カラーコード (Hex) | 用途・説明 |
| --- | --- | --- |
| **Main Background** | `#FBF7EE` | 画面全体のベース背景（温かみのある生成り色） |
| **Card Background** | `#FFFDF9` | 単語カード・入力フィールド等の背景（ソフトホワイト） |
| **Primary Accent** | `#5F9E98` | アクティブ状態のボタン（ソート切替の`Chap`等）、プログレスバー |
| **Secondary Accent** | `#ECA882` | フィルタータグ（`Unlearned`, `CEFR`等）の背景・アクセント |
| **Bottom Bar** | `#D4B86A` | 画面下部ナビゲーションバーの背景 |
| **Text Primary** | `#2C302E` | 英単語タイトル、見出し等の主要テキスト |
| **Text Secondary** | `#6B726E` | 発音記号、日本語訳、例文等の補足テキスト |
| **Border / Line** | `#E5DEC9` | カードや区切り線、非アクティブタグのボーダー |

## 2. タイポグラフィ (Typography)

| 項目 | フォント指定 (推奨) | サイズ / ウェイト | 用途 |
| --- | --- | --- | --- |
| **Word Title** | `Serif` (e.g., Georgia / Times New Roman) | `22pt` / Bold | 英語単語の見出し（`Mitigate` 等） |
| **Phonics / Category** | `Sans-Serif` (e.g., SF Pro / Noto Sans JP) | `13pt` / Regular | 発音記号、カテゴリタイトル |
| **Japanese Meaning** | `Sans-Serif` (e.g., Hiragino Sans / Noto Sans JP) | `15pt` / Medium | 日本語の訳語 |
| **Usage Note / Example** | `Sans-Serif` | `12pt` / Regular | 例文・解説文 |
| **Pixel Font** (Stamp/Section) | `Press Start 2P` / `DotGothic16` | `10pt - 14pt` | ドット絵セクション（`Learned %` や進捗数） |

## 🔲 3. コンポーネント & 形状仕様 (Components & Shapes)

* **単語カード (Word Card)**
* **角丸 (Border Radius):** `16px`
* **シャドウ (Box Shadow):** `Offset(0, 2), Blur: 8, Color: #000000 (Opacity 4%)`
* **パディング (Padding):** 内側 `16px` / カード間 `12px`


* **検索バー & フィルタータグ (Search Bar & Filter Tags)**
* **検索バー:** 高さ `38px`、角丸 `12px`、背景 `#EFEAE0`
* **フィルターバー構造:** 横スクロール対応（`SingleChildScrollView`）でスマホ画面の横幅制限に対応
* **フィルタータグ (Toggle & Dropdown):**
  - **未暗記 (Unlearned):** トグル式（未選択時は全対象、タップでON/OFF）
  - **お気に入り (Favorite):** トグル式（未暗記と同時選択・AND条件対応）
  - **ドロップダウン群 (Dropdown):** `CEFR: 全て ▾`、`Chap: 全て ▾`、`A-Z: 全て ▾`、`Category: 全て ▾`（すべて高さ `28px`、角丸 `8px`、パステルピル型）
  - ※「すべて」ボタンは廃止。何も選択されていない時は自動的にすべて対象。
* **和訳常時表示スイッチ:** スクロールバー末尾にコンパクト配置（`Switch`）


* **ソート切替ボタン (Sort Toggle)**
* **構造:** 3分割のセグメントコントロール（`Chap` / `A-Z` / `Category`）
* **角丸:** `8px`
* **アクティブ状態:** 背景 `#5F9E98` + 白文字

## 🎮 4. ドット絵・進捗ヘッダー仕様 (Pixel Art & Progress Bar)

* **ヘッダー画像 (Category Header):**
* **スタンプ表示:** 16×16 px または 32×32 px ベースのドットイラスト（ドット感を損なわないよう `ImageRendering: Pixelated` を指定）


* **進捗バー (Learned Rate Bar):**
* **高さ:** `12px`
* **角丸:** `6px`
* **背景:** `#E8DEC8`
* **進捗カラー:** `#ECA882`（グラデーションまたは単色）
* **カウンター:** ドットフォントで `8/50` のように右上に配置



---

## 📜 5. スクロール・ヘッダー動作仕様 (Sticky Header)

1. **スクロール時挙動:**
* 画面を下にスクロールすると、上部の「検索バー」および「フィルター・ソートエリア」は画面上方へスライドアウトして非表示になります。


2. **固定要素 (Sticky Component):**
* `Category: Fruits & Vegetables` のドットイラストおよび進捗バーが含まれる区切りヘッダーは、画面最上部に固定（Sticky）され、コンテンツのみがその下を潜り抜けるようにスクロールします。
