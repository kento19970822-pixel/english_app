# 📘 英単語学習アプリ システム要件定義書（詳細決定版・第12版・完全統合版）

## 1. 全体概要・システム要件

### 1.1 全体概要

本アプリは、ゲームの爽快感（2レーン落下式アクション）と科学的な記憶定着アルゴリズム（エビングハウスの忘却曲線モデル）を融合させた英単語学習アプリです[cite: 13]。
直感的なクイズゲームによるアウトプットと、単語帳でのスワイプ/長押し/手動チェック操作によるインプット・手動メンテ、そして毎日の連続プレイ（ストリーク）をトリガーとしたコレクター要素（プロシージャル生成ドット絵スタンプ図鑑）により、学習の習慣化と高効率な記憶定着を実現します[cite: 13]。

### 1.2 システム要件

* **対応プラットフォーム**: Windows (Desktop), Web, iOS, Android (Flutterクロスプラットフォーム)[cite: 13]
* **開発言語 / フレームワーク**: Dart / Flutter[cite: 13]
* **ローカルデータベース**: Drift (SQLite)[cite: 13]
* **音声・効果音機能**: FlutterTts (TTS再生) / AudioPlayers (SE再生)[cite: 13]
* **開発＆Git運用ポリシー**:
  * CSVパース処理等は外部パッケージ（`csv`パッケージ等）に依存せず、Dart標準機能（正規表現・手動パース）のみで実装する[cite: 13]。
  * コード提示時は必ず管理番号（例: `VER-20260819-xxx`）を発番・提示する[cite: 13]。
  * コミットを行う際は、アプリ起動確認を実施した上でメッセージ冒頭または末尾に `[動作確認済]` と明記する[cite: 13]。
  * 機能開発時は直接 `master` ブランチを変更せず、機能ブランチ（例: `feature/xxx`）を作成して作業・動作確認後にマージする[cite: 13]。
  * UI/UXの固定化および崩れ防止のため、画面のスクリーンショットを `docs/design/` または `design/` 配下に保存・管理する（例: `design/バージョン名/game_screen_xx.png`）[cite: 13]。
  * **【画面ナビゲーション保護ルール】ゲーム実行中（ゲームスタート〜リザルト画面終了およびバックジェスチャー等による中断時）は、画面下部のボトムナビゲーションバーを完全に非表示（`null`）に固定する。画面離脱時は `PopScope` 経由で必ず離脱検知を行い、呼び出し元のナビゲーションバー表示状態を確実に復元（`false` 通知）させる。**[cite: 13]
  * 2レーン落下ゲーム画面にはプレイの邪魔にならない極薄（Opacity 0.2等）の3分割判定線（Fast / Normal / Slow）を表示し、判定位置に応じた階層化演出（エフェクト・テキスト・効果音）を適用する[cite: 13]。
  * 機能の区切りごとに「次に試すこと」＋「動作確認後に実行する Git コミット指示」をセットで案内する[cite: 13]。

### 2.2 詳細アルゴリズム・ルール仕様

#### 🎮 ① 2レーン落下ゲームのゲーム性・動作メカニズム

1. **画面レイアウトと左右独立レーン**:
   * 画面上部に統合スコア・コンボバーを配置[cite: 13]。
   * 下部は左右に完全分割された2つのレーン（左: ブルー基調、右: インディゴ基調）で構成[cite: 13]。
   * 各レーンは「上部: 落下エリア（単語カード＋3分割判定線＋フィードバック）」と「下部: 4択選択肢ボタンエリア」に分離[cite: 13]。

2. **左右2レーンの時差スタート・並行制御**:
   * **ゲーム開始時**: 右レーンが第1問目として即時スタート[cite: 13]。
   * **左レーンのタイムラグ発信**: 右レーン開始から **2秒後** に左レーンが第2問目として追随スタート[cite: 13]。右レーンで即答した場合は2秒を待たずに即時発進[cite: 13]。

3. **単語落下・選択肢生成・音声（TTS）ルール**:
   * **落下アニメーション**: 単語カードが指定秒数（デフォルト 8秒）かけて垂直落下[cite: 13]。
   * **音声再生（TTS）**: 出題単語が画面にセットされた瞬間、自動で英語音声を1回再生[cite: 13]。
   * **4択選択肢**: 正解日本語訳1個 ＋ 同レベル内の他単語から抽出した誤答日本語訳3個[cite: 13]。

4. **解答判定・コンボ・SE・フィードバック演出**:
   * **正解時**: 正解効果音（`correct.mp3`）、コンボアップ、位置に応じた加点（Fast: +50pt / Normal: +30pt / Slow: +10pt）[cite: 13]。
   * **誤答時・タイムオーバー時**:
     * 不正解効果音（`wrong.mp3`）、コンボリセット、**-50 pt 減算**、および **制限フラグ（当日上限70pt）を即時付与**[cite: 13]。
     * 未クリア単語は問題キューの末尾へ再ロード[cite: 13]。

5. **画面離脱時の状態保護（PopScope）**:
   * アクションバーの戻るボタン、物理バックボタン、ジェスチャーナビゲーションによる離脱が発生した際、`PopScope` でこれを検知し `onGameStateChanged(false)` を発火[cite: 13]。ボトムナビゲーションバーを確実に親画面へ復元表示する[cite: 13]。

---

#### 🧠 ② 定着度ポイント（retention_point）およびフラグ制御ルール

1. **基本設計**:
   * **ポイント範囲**: `0` 〜 `100` pt（初期値: 0 pt）[cite: 13]
   * **暗記済みフラグ（`is_memorized`）**: ポイントが **80 pt 以上** に達した瞬間に自動で `true` となる[cite: 13]。**忘却減算等により80pt未満になっても自動では外れない**（単語帳の更新ボタン F-09 による手動メンテで一括解除）[cite: 13]。
   * **1ゲーム1変動原則**: 1プレイ（1セッション）中に同一単語が復習用等で複数回出現しても、**ポイント変動処理は初回選択時の1回のみ**行う[cite: 13]。2回目以降の回答や誤答によるポイント変動・フラグ更新は発生しない[cite: 13]。ゲームを一旦終了・中断・完了し、新しくゲームを開始した場合は別セッションとなり再び変動対象となる[cite: 13]。

2. **クイズ解答時の加算・減算ライン**:
   * 🟢 **上部 1/3 ゾーン（Fast）**: `+50 pt` ＋ 【演出: 「💥 Great!!」＆高音SE】[cite: 13]
   * 🔵 **中部 2/3 ゾーン（Normal）**: `+30 pt` ＋ 【演出: 「👍 Good!」＆通常SE】[cite: 13]
   * 🟡 **下部 3/3 ゾーン（Slow）**: `+10 pt` ＋ 【演出: 「👌 OK」】[cite: 13]
   * 🔴 **誤答 / タイムオーバー**: `-50 pt` ＋ 【制限フラグ付与】 ＋ 【演出: 「❌ Miss」＆失敗SE】[cite: 13]

3. **制限フラグ（`is_restricted` / 当日上限70pt制限）**:
   * **付与条件**: クイズで誤答・タイムオーバーとなった場合、または単語帳で左スワイプ（0ptリセット）を行った場合[cite: 13]。
   * **効果**: 制限フラグが立っている単語は、同日中にどれだけ正解しても **70 pt が上限（頭打ち）** となり、その日中は暗記済み（80pt）に到達できない[cite: 13]。
   * **解除条件**: 日付が変わる（0:00跨ぎ）とアプリ起動時の日跨ぎ同期処理により自動的に解除され、100ptまで獲得可能になる[cite: 13]。

4. **単語帳での直接操作ルール（実装済）**:
   * **右スワイプ**: 定着度を一律 **80 pt** にセットし、`is_memorized = true` にする[cite: 13]。
   * **左スワイプ**: 定着度を **0 pt** にリセットし、`is_memorized = false` に変更 ＋ **制限フラグ（`is_restricted = true`）を同時付与**[cite: 13]。
   * **リアルタイム同期**: 単語帳とお気に入り状態・定着度ポイントがDBを介して相互に即座に同期される[cite: 13]。

5. **暗記フラグ更新（一括メンテ）機能（F-09実装済）**:
   * 単語帳等の「暗記フラグ更新」処理実行時、忘却曲線で `retention_point < 80` に下がっている「暗記済み」単語の `is_memorized` を一括で `false` に更新する[cite: 13]。

#### 📉 ③ 忘却曲線ロジックと1日1回日跨ぎ一括処理

アプリ起動時（または日付変更後の初回起動時）、前回の実行日（`last_daily_sync_date`）と今日の日付（`YYYY-MM-DD`）を比較し、**日付が変わっている場合のみ1日1回の一括更新処理**を実行する[cite: 13]。

1. **一括処理内容**:
   * **忘却減算**: 各単語の最終解答日時からの経過日数と累計正答回数をもとに、定着度（`retention_point`）のみを減算[cite: 13]。
   * **制限解除**: 制限フラグ（`is_restricted`）をすべて解除[cite: 13]。
   * ※パフォーマンス維持のため1日1回のみ実行[cite: 13]。`is_memorized` は自動変更しない[cite: 13]。

2. **計算式**:

$$\text{次回定着度} = \text{現在の定着度} \times \left( 1 - \frac{\text{経過日数}}{\text{経過日数} + 2 + (\text{正解回数} \times 2)} \right)$$
[cite: 13]

#### 🎮 ④ クイズモード別詳細ルール

1. **学習モード（ステップアップ系）**:
   * **選択**: チャプター単位で実行（初期値: Ch. 1）[cite: 13]。
   * **出題対象（案B採用）**: 
     * 「`is_memorized == false`（未暗記）」**または**「`retention_point < 70 pt`（忘却減算による復習対象）」[cite: 13]
     * かつ「`is_restricted == false`（当日の上限70pt制限がかかっていない）」単語からランダムに出題[cite: 13]。
   * **進捗管理と自動移行**:
     * チャプター内の全100単語に対する暗記率（%）を算出[cite: 13]。
     * 100語セッション/周回終了時点で **暗記率 90% 以上** を達成していた場合、リザルト画面で「Ch.X MASTER! 🎉」バッジ・ポップアップ演出を表示し、**自動的に次のチャプターへ移行・解放**する[cite: 13]。

2. **チャレンジモード（アーケード＆復習系）**:
   * **選択**: 制限時間 1分間 / 100問連続出題[cite: 13]。
   * **出題対象**: 全単語（暗記済み含む）からランダム[cite: 13]。
   * **復習ボーナス（即答補正）**: 暗記済み単語が選択され、上部 1/3（Fast +50pt）で即答できた場合、忘却曲線で下がりかけていたポイントを完全回復するボーナスを与える[cite: 13]。

#### 📖 ⑤ 単語帳の粘着ヘッダー＆UI表示

1. **粘着ヘッダー（Sticky Chapter Header）**:
   * チャプターごとの境界バーに、該当チャプターの単語数および暗記率を明示（例: `Ch. 1 (暗記率: 85% - 85/100語)`）[cite: 13]。
2. **カード表示**:
   * 左端に暗記済みインジケータ、中央に英単語・発音記号・和訳（長押し一時表示対応）、右端に発音ボタン・レベルチャプターバッジ・お気に入り☆ボタンを配置[cite: 13]。
   * 制限フラグ保持単語には「⚠️ 本日上限70pt」の制限アイコンを付与[cite: 13]。

#### 🎨 ⑥ プロシージャル生成ドット絵スタンプ・抽選・手動拡張ロジック（F-11 / F-12）

1. **ドット絵スタンプの完全自動生成（CustomPainter描画）**:
   * アセット画像ファイルに依存せず、Dartコード内でカラーパレット、顔・装飾パーツ、フレーム、背景エフェクトのシード値を組み合わせ、レトロ感溢れるドット絵スタンプを生成・描画する。

2. **1日1回押印と安全な獲得判定ルール**:
   * **判定タイミング**: その日の「1回目のゲームクリア時（リザルト画面前）」に自動判定・演出表示（日跨ぎ管理: `YYYY-MM-DD`）。
   * **物理的達成不能の回避**: 当日初回ゲームのプレイ内容（スコア・コンボ）だけでなく、「累積学習日数」「ストリーク（連続日数）」「総暗記数」「暗記チャプター数」などの**到達済み累積ステータス**を解放条件に設定。未達成条件のスタンプが抽選された場合でもフォールバックとして条件なし/達成済みスタンプが割り当てられるため、必ず毎日スタンプを獲得できる。

3. **レア度と出現率（固定割合）**:
   * 🟢 **Normal (70%)**: シンプルな単色〜2色カラー / 白黒・基本背景
   * 🔵 **Rare (22%)**: カラフルなカラー / メガネ・リボン等の装飾パーツ / 青〜銀枠
   * 🟡 **Super Rare (8%)**: 虹色・金ピカカラー / キラキラエフェクト / 金枠

4. **初期生成（Phase 1）と難易度レベル感**:
   * 初回起動時に **20個** のスタンプおよび条件を生成（Normal: 14 / Rare: 4 / SR: 2）。
   * 1週間で10チャプター（約1000語）を暗記完了するペースに合わせて、7日間ですべての開放条件を満たせるレベル感（連続1〜7日、暗記数100〜1000語、チャプター1〜10章達成等）に設定。

5. **手動による「図鑑拡張ボタン」と段階的アップデート演出**:
   * **出現条件**: 現在解放されている図鑑の **獲得率が 80% 以上**（Phase 1 では 20個中 16個獲得）に達すると、図鑑画面の上部に「✨ 新しい図鑑を解放する（Phase UP）」ボタンが出現。
   * **生成演出**: ユーザーがボタンをタップすると、ダイアログ・エフェクト演出が走り、**新たに20個のスタンプと図鑑枠（合計 40個）が手元で生成される瞬間を観賞**できる。
   * **上限ガード付き難易度スケーリング**:
     * 追加生成される条件（Phase 2 以降）は自動でステップアップする。
     * **安全ガードルール**: 「暗記単語数」は `min(目標数, DB内の総登録単語数)`、「チャプター数」は `min(目標数, DB内の総チャプター数)`、「暗記率」は `100%` を上限（キャップ）とし、アプリ内の物理的上限を超えて解放不可能になることを完全に防止する。上限到達後は「通算プレイ日数」「総クリアゲーム数」「ハイスコア」などの永続インクリメント項目へ自動シフトする。
