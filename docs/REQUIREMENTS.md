# 📘 英単語学習アプリ システム要件定義書（詳細決定版・第11版）

## 1. 全体概要・システム要件

### 1.1 全体概要

本アプリは、ゲームの爽快感（2レーン落下式アクション）と科学的な記憶定着アルゴリズム（エビングハウスの忘却曲線モデル）を融合させた英単語学習アプリです。
直感的なクイズゲームによるアウトプットと、単語帳でのスワイプ/長押し/手動チェック操作によるインプット・手動メンテ、そして毎日の連続プレイ（ストリーク）をトリガーとしたコレクター要素（スタンプ図鑑）により、学習の習慣化と高効率な記憶定着を実現します。

### 1.2 システム要件

* **対応プラットフォーム**: Windows (Desktop), Web, iOS, Android (Flutterクロスプラットフォーム)
* **開発言語 / フレームワーク**: Dart / Flutter
* **ローカルデータベース**: Drift (SQLite)
* **音声・効果音機能**: FlutterTts (TTS再生) / AudioPlayers (SE再生)
* **開発＆Git運用ポリシー**:
  * CSVパース処理等は外部パッケージ（`csv`パッケージ等）に依存せず、Dart標準機能（正規表現・手動パース）のみで実装する。
  * コード提示時は必ず管理番号（例: `VER-20260819-xxx`）を発番・提示する。
  * コミットを行う際は、アプリ起動確認を実施した上でメッセージ冒頭または末尾に `[動作確認済]` と明記する。
  * 機能開発時は直接 `master` ブランチを変更せず、機能ブランチ（例: `feature/xxx`）を作成して作業・動作確認後にマージする。
  * UI/UXの固定化および崩れ防止のため、画面のスクリーンショットを `design/` 配下に保存・管理する（例: `design/バージョン名/game_screen_xx.png`）。
  * **【画面ナビゲーション保護ルール】ゲーム実行中（ゲームスタート〜リザルト画面終了およびバックジェスチャー等による中断時）は、画面下部のボトムナビゲーションバーを完全に非表示（`null`）に固定する。画面離脱時は `PopScope` 経由で必ず離脱検知を行い、呼び出し元のナビゲーションバー表示状態を確実に復元（`false` 通知）させる。**
  * 2レーン落下ゲーム画面にはプレイの邪魔にならない極薄（Opacity 0.2等）の3分割判定線（Fast / Normal / Slow）を表示し、判定位置に応じた階層化演出（エフェクト・テキスト・効果音）を適用する。
  * 機能の区切りごとに「次に試すこと」＋「動作確認後に実行する Git コミット指示」をセットで案内する。

### 2.2 詳細アルゴリズム・ルール仕様

#### 🎮 ① 2レーン落下ゲームのゲーム性・動作メカニズム

1. **画面レイアウトと左右独立レーン**:
   * 画面上部に統合スコア・コンボバーを配置。
   * 下部は左右に完全分割された2つのレーン（左: ブルー基調、右: インディゴ基調）で構成。
   * 各レーンは「上部: 落下エリア（単語カード＋3分割判定線＋フィードバック）」と「下部: 4択選択肢ボタンエリア」に分離。

2. **左右2レーンの時差スタート・並行制御**:
   * **ゲーム開始時**: 右レーンが第1問目として即時スタート。
   * **左レーンのタイムラグ発信**: 右レーン開始から **2秒後** に左レーンが第2問目として追随スタート。右レーンで即答した場合は2秒を待たずに即時発進。

3. **単語落下・選択肢生成・音声（TTS）ルール**:
   * **落下アニメーション**: 単語カードが指定秒数（デフォルト 8秒）かけて垂直落下。
   * **音声再生（TTS）**: 出題単語が画面にセットされた瞬間、自動で英語音声を1回再生。
   * **4択選択肢**: 正解日本語訳1個 ＋ 同レベル内の他単語から抽出した誤答日本語訳3個。

4. **解答判定・コンボ・SE・フィードバック演出**:
   * **正解時**: 正解効果音（`correct.mp3`）、コンボアップ、位置に応じた加点（Fast: +50pt / Normal: +30pt / Slow: +10pt）。
   * **誤答時・タイムオーバー時**:
     * 不正解効果音（`wrong.mp3`）、コンボリセット、**-50 pt 減算**、および **制限フラグ（当日上限70pt）を即時付与**。
     * 未クリア単語は問題キューの末尾へ再ロード。

5. **画面離脱時の状態保護（PopScope）**:
   * アクションバーの戻るボタン、物理バックボタン、ジェスチャーナビゲーションによる離脱が発生した際、`PopScope` でこれを検知し `onGameStateChanged(false)` を発火。ボトムナビゲーションバーを確実に親画面へ復元表示する。

---

#### 🧠 ② 定着度ポイント（retention_point）およびフラグ制御ルール

1. **基本設計**:
   * **ポイント範囲**: `0` 〜 `100` pt（初期値: 0 pt）
   * **暗記済みフラグ（`is_memorized`）**: ポイントが **80 pt 以上** に達した瞬間に自動で `true` となる。**忘却減算等により80pt未満になっても自動では外れない**（単語帳の更新ボタン F-09 による手動メンテで一括解除）。
   * **1ゲーム1変動原則**: 1プレイ（1セッション）中に同一単語が復習用等で複数回出現しても、**ポイント変動処理は初回選択時の1回のみ**行う。2回目以降の回答や誤答によるポイント変動・フラグ更新は発生しない。ゲームを一旦終了・中断・完了し、新しくゲームを開始した場合は別セッションとなり再び変動対象となる。

2. **クイズ解答時の加算・減算ライン**:
   * 🟢 **上部 1/3 ゾーン（Fast）**: `+50 pt` ＋ 【演出: 「💥 Great!!」＆高音SE】
   * 🔵 **中部 2/3 ゾーン（Normal）**: `+30 pt` ＋ 【演出: 「👍 Good!」＆通常SE】
   * 🟡 **下部 3/3 ゾーン（Slow）**: `+10 pt` ＋ 【演出: 「👌 OK」】
   * 🔴 **誤答 / タイムオーバー**: `-50 pt` ＋ 【制限フラグ付与】 ＋ 【演出: 「❌ Miss」＆失敗SE】

3. **制限フラグ（`is_restricted` / 当日上限70pt制限）**:
   * **付与条件**: クイズで誤答・タイムオーバーとなった場合、または単語帳で左スワイプ（0ptリセット）を行った場合。
   * **効果**: 制限フラグが立っている単語は、同日中にどれだけ正解しても **70 pt が上限（頭打ち）** となり、その日中は暗記済み（80pt）に到達できない。
   * **解除条件**: 日付が変わる（0:00跨ぎ）とアプリ起動時の日跨ぎ同期処理により自動的に解除され、100ptまで獲得可能になる。

4. **単語帳での直接操作ルール（実装済）**:
   * **右スワイプ**: 定着度を一律 **80 pt** にセットし、`is_memorized = true` にする。
   * **左スワイプ**: 定着度を **0 pt** にリセットし、`is_memorized = false` に変更 ＋ **制限フラグ（`is_restricted = true`）を同時付与**。
   * **リアルタイム同期**: 単語帳とお気に入り状態・定着度ポイントがDBを介して相互に即座に同期される。

5. **暗記フラグ更新（一括メンテ）機能（F-09実装済）**:
   * 単語帳等の「暗記フラグ更新」処理実行時、忘却曲線で `retention_point < 80` に下がっている「暗記済み」単語の `is_memorized` を一括で `false` に更新する。

#### 📉 ③ 忘却曲線ロジックと1日1回日跨ぎ一括処理

アプリ起動時（または日付変更後の初回起動時）、前回の実行日（`last_daily_sync_date`）と今日の日付（`YYYY-MM-DD`）を比較し、**日付が変わっている場合のみ1日1回の一括更新処理**を実行する。

1. **一括処理内容**:
   * **忘却減算**: 各単語の最終解答日時からの経過日数と累計正答回数をもとに、定着度（`retention_point`）のみを減算。
   * **制限解除**: 制限フラグ（`is_restricted`）をすべて解除。
   * ※パフォーマンス維持のため1日1回のみ実行。`is_memorized` は自動変更しない。

2. **計算式**:

$$\text{次回定着度} = \text{現在の定着度} \times \left( 1 - \frac{\text{経過日数}}{\text{経過日数} + 2 + (\text{正解回数} \times 2)} \right)$$

#### 🎮 ④ クイズモード別詳細ルール

1. **学習モード（ステップアップ系）**:
   * **選択**: チャプター単位で実行（初期値: Ch. 1）。
   * **出題対象（案B採用）**: 
     * 「`is_memorized == false`（未暗記）」**または**「`retention_point < 70 pt`（忘却減算による復習対象）」
     * かつ「`is_restricted == false`（当日の上限70pt制限がかかっていない）」単語からランダムに出題。
   * **進捗管理と自動移行**:
     * チャプター内の全100単語に対する暗記率（%）を算出。
     * 100語セッション/周回終了時点で **暗記率 90% 以上** を達成していた場合、リザルト画面で「Ch.X MASTER! 🎉」バッジ・ポップアップ演出を表示し、**自動的に次のチャプターへ移行・解放**する。

2. **チャレンジモード（アーケード＆復習系）**:
   * **選択**: 制限時間 1分間 / 100問連続出題。
   * **出題対象**: 全単語（暗記済み含む）からランダム。
   * **復習ボーナス（即答補正）**: 暗記済み単語が選択され、上部 1/3（Fast +50pt）で即答できた場合、忘却曲線で下がりかけていたポイントを完全回復するボーナスを与える。

#### 📖 ⑤ 単語帳の粘着ヘッダー＆UI表示

1. **粘着ヘッダー（Sticky Chapter Header）**:
   * チャプターごとの境界バーに、該当チャプターの単語数および暗記率を明示（例: `Ch. 1 (暗記率: 85% - 85/100語)`）。
2. **カード表示**:
   * 左端に暗記済みインジケータ、中央に英単語・発音記号・和訳（長押し一時表示対応）、右端に発音ボタン・レベルチャプターバッジ・お気に入り☆ボタンを配置。
   * 制限フラグ保持単語には「⚠️ 本日上限70pt」の制限アイコンを付与。
